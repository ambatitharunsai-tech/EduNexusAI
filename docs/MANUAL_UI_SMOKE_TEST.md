## Local Reset Safety

The local dashboard identified its source as `Synthetic in-memory dataset`. Reset is guarded by `require_staff_user` and `CsvService.reset_synthetic_demo_dataset()` rejects when `is_database_configured()` is true. Automated tests assert the persistent-mode 409. Do not run reset against any production system; this checklist’s local reset did not connect to one.
